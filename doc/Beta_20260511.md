# ⚪ Atleti-news Frontend System Documentation v1.0 (Beta)

본 문서는 **Atleti-news** 프로젝트의 1차 베타 버전 배포 기준 프론트엔드 시스템 설계, UI/UX 전략, 그리고 개발 회고를 설명함.

---

## 1. 시스템 아키텍처 개요
본 시스템은 아틀레티코 마드리드의 현지 소식을 한국 팬들에게 가장 빠르고 쾌적하게 전달하기 위한 **"SEO 최적화 기반 뉴스 포털"**을 목표로 설계됨.

### ⚙️ 기술 스택
- **프레임워크**: Next.js 14+ (App Router 기반)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **아이콘 및 UI 컴포넌트**: Lucide React, Headless UI
- **데이터 페칭 및 연동**: OpenAPI TypeScript (codegen), fetch API
- **SNS 렌더링**: `react-tweet`
- **배포 및 인프라**: Vercel

---

## 2. 핵심 비즈니스 로직 및 컴포넌트 구조

### 2.1 서버 사이드 렌더링 (SSR) 및 구조
*   **Next.js App Router**: `app/page.tsx` 등 주요 페이지를 서버 컴포넌트로 구현하여 검색 엔진 최적화(SEO) 점수를 극대화하고 초기 로딩 속도를 크게 단축함.
*   **컴포넌트 분리**: 뉴스 피드 리스트, 매치 결과 카드(`MatchResultCard`), 트윗 렌더러 등을 독립적인 컴포넌트로 분리하여 재사용성과 유지보수성을 높임.

### 2.2 API 클라이언트 자동화 (`openapi-ts`)
*   백엔드(Spring Boot)에서 제공하는 Swagger 문서를 기반으로 클라이언트 코드를 자동 생성함.
*   이를 통해 백엔드 API 스펙 변경 시 타입스크립트 에러로 즉각 인지가 가능해져 프론트-백 연동의 안정성을 확보함.

---

## 3. UI/UX 및 디자인 컨셉

### 3.1 로히블랑코(Red & White) 테마 적용
*   아틀레티코 마드리드의 상징색인 적색과 백색을 활용하여 브랜드 아이덴티티를 확립함.

### 3.2 반응형 카드 UI 및 모바일 최적화 (Mobile-First)
*   사용자의 대다수가 스마트폰으로 소식을 접한다는 점을 고려해, 작은 화면에서도 가독성이 뛰어난 카드형 UI를 메인으로 채택함.
*   기사 썸네일, AI 3줄 요약, 원문 링크 등이 한눈에 들어오도록 레이아웃을 구성함.
*   모바일에서 필터가 보이지 않는 현상이 있음 -> 수정 필요.

### 3.3 트위터(X) 네이티브 렌더링
*   `react-tweet` 라이브러리를 활용하여, 백엔드에서 넘겨받은 트윗 ID만으로 공식 트위터 앱과 완벽히 동일한 UI를 렌더링함.

---

## 4. 배포 및 성능 최적화

### 4.1 Vercel 기반 무중단 배포
*   GitHub 리포지토리와 Vercel을 연동하여, 코드 푸시 시 즉각적으로 빌드 및 글로벌 CDN 배포가 이루어지는 CI/CD 파이프라인을 구축함.

### 4.2 외부 이미지 차단 우회 및 로딩 최적화
*   Marca 등 외부 언론사의 이미지 임베딩 시 발생하는 403 Forbidden 에러를 방지하기 위해 `<meta name="referrer" content="no-referrer">` 태그를 적용함.
*   Next.js의 `next/image`를 활용하여 이미지 리사이징, WebP 변환, Lazy Loading을 기본 적용하여 코어 웹 바이탈 성능을 끌어올림.

## 5. 현안 및 향후 개선 과제 (Challenges & Future Roadmap)

### 5.1 UI/UX 고도화
*   **뉴스 카테고리 필터링**: 백엔드 카테고리 분류 완료 시, 프론트엔드에도 최상단 탭 기반 필터링 기능을 추가할 예정임.
*   **무한 스크롤 / 페이지네이션 유지**: 페이지 이동 후 뒤로가기 시 기존 스크롤 위치 및 데이터 상태가 유지되도록 고도화가 필요함.

### 5.2 장애 대응 UI (Fallback)
*   백엔드 데이터 수집 지연이나 API 에러 발생 시, "소식을 가져오는 중입니다..."와 같은 스켈레톤 UI와 에러 바운더리 처리를 강화할 예정임.

### 5.3 SEO 및 서비스 품질 강화
*   **SEO 강화**: 검색 노출 빈도를 높이기 위해 메타 태그 최적화, 사이트맵(Sitemap) 생성, 시맨틱 마크업 강화 등 고도화된 SEO 작업을 진행할 예정임.

## 6. 회고 (Retrospective)

전문 디자이너가 아니어서 처음에 디자인을 구상할 때 어려움이 있었음. 이를 해결하기 위해 아틀레티코 마드리드 공식 웹사이트를 적극 참고하였고, 'Loveable'이라는 AI 디자인 웹 서비스의 도움을 받아 UI를 기획함. 특히 구단 로고 사용 등 저작권에 위배되지 않는 선에서 팀의 정체성을 살려 디자인하는 과정이 꽤 까다롭고 힘들었음.

배포의 경우, Vercel을 통해 프론트엔드를 배포해 보니 백엔드 배포 과정보다 훨씬 수월하고 직관적이어서 편했음. 한 가지 아쉬운 점은 파비콘(favicon)을 'nano banana'를 통해 제작해 보았는데 결과물이 개인적으로 마음에 들지 않는다는 점.

향후 계획으로는, 대다수의 팬들이 모바일 기기를 통해 이 웹을 방문할 것이라 생각되므로, 지금보다 더욱 철저하게 모바일 친화적인 UI로 전면 개편을 진행해야겠음.
