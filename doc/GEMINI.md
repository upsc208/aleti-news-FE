# ⚪ 프로젝트명: Saúl-Correa Bridge (프론트엔드 통합 설계서)

## 1. 프로젝트 개요 및 디자인 컨셉
- **목표**: 쾌적한 사용자 경험(UX)과 검색 엔진 최적화(SEO)를 갖춘 아틀레티코 마드리드 뉴스 포털.
- **디자인 테마**:
    - 아틀레티코의 상징색인 **로히블랑코(Red & White)**와 네이비 블루를 메인 컬러로 사용.
    - 선수의 이미지를 마스코트나 브랜딩 요소로 활용.
- **핵심 가치**: 모바일 최적화, 실시간성 시각화, 고성능 렌더링.

## 2. 기술 스택 (Tech Stack)
- **프레임워크**: Next.js 14+ (App Router 기반)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **컴포넌트 라이브러리**: Lucid React (아이콘), Headless UI (접근성)
- **상태 관리/데이터 페칭**: React Query 또는 SWR (백엔드 API 호출 최적화)
- **SNS 렌더링**: `react-tweet` (X/Twitter 공식 UI 복원용)
- **배포**: Vercel

## 3. 주요 기능 및 요구사항
### 3.1 뉴스 대시보드 (News Feed)
- **서버 사이드 렌더링(SSR)**: 뉴스 데이터를 서버에서 미리 그려 SEO 점수를 극대화하고 초기 로딩 속도 단축.
- **카드형 UI**:
    - 제목, AI 3줄 요약, 출처, 이미지 썸네일을 포함한 깔끔한 레이아웃.
    - (최신순 및 다양한 필터 제공.
- **이미지 로딩 최적화**: `next/image`를 사용하여 이미지 리사이징 및 Lazy Loading 적용.

### 3.2 SNS 위젯 통합
- **X(Twitter) 연동**: 백엔드에서 수집한 트윗 ID를 기반으로 `react-tweet`을 호출하여 공식 트위터 앱과 동일한 느낌의 UI 제공.
- **다크 모드 지원**: 사용자 설정에 따른 테마 전환 대응.

### 3.3 비기능적 요구사항 (성능 및 보안)
- **이미지 차단 우회**: 마르카(Marca) 등 외부 이미지 임베딩 시 차단을 방지하기 위해 `<meta name="referrer" content="no-referrer">` 적용.
- **반응형 디자인**: 모바일 사용자가 많은 팬덤 특성을 고려하여 Mobile-First 디자인 구현.
- **에러 핸들링**: 백엔드 API 장애 시 "사울과 코레아가 소식을 가져오는 중입니다..."와 같은 친절한 Fallback 메시지 및 스켈레톤 UI 노출.

## 4. 페이지 구조 (App Router)
- `app/layout.tsx`: 전역 내비게이션 바 및 아틀레티코 테마 적용.
- `app/page.tsx`: 메인 뉴스 피드 (SSR 방식).
- `app/news/[id]/page.tsx`: 뉴스 상세 페이지 (상세 요약 및 원문 링크).

## 🚀 Gemini CLI를 위한 초기 지시어
"위 명세서를 기반으로 프론트엔드 개발을 시작하자.

1. **Next.js 14(App Router)**와 **Tailwind CSS**를 사용하는 프로젝트 뼈대를 구성해줘.
2. 아틀레티코 마드리드의 **적색과 백색**을 메인 테마로 하는 `Layout`과 `Header`를 만들어줘.
3. 백엔드 API(`/api/v1/news`)에서 데이터를 가져와 **서버 컴포넌트**에서 렌더링하는 뉴스 카드 리스트 페이지를 작성해줘.
4. **`react-tweet`** 라이브러리를 설치하고, 트윗 ID가 있을 경우 공식 트윗 UI로 보여주는 컴포넌트를 설계해줘.
5. 코드 전반에 '사울(Seoul)'과 '코레아(Korea)' 테마를 디자인 요소나 주석으로 센스 있게 녹여줘."
